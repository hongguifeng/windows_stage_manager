# Windows Stage Manager 0.6.1

发布日期：2026-09-11。

## 改动

- 拖动已经激活的窗口后，保留手动位置，不重新求解或移动后台窗口。
- 右键激活（包括重复前台事件）取消旧事务、激活重试和后台补排，不触发布局计算或移动。
- 抑制状态跨定期刷新和菜单焦点往返保留；正常激活另一个受管理窗口后恢复布局。
- 增加独立布局抑制回归测试，同步中英文说明、设计文档及版本元数据。
- 包含上一版本之后已提交的可见性分析及健康监视改动。
