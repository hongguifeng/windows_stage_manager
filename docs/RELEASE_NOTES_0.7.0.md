# Windows Stage Manager 0.7.0

发布日期：2026-09-12。

## 改动

- 标题栏求解器改为确定性左上阶梯（固定点）契约：只发布可验证的连续前缀，后缀越出工作区（staircase_outside_work_area）或被固定窗口遮挡（staircase_blocked）时停止，不再尝试远距离候选搜索与 beam 回退。
- v0.6.1 标签仍基于旧候选搜索求解器；本版本是首个包含确定性阶梯契约、手势后保留手动位置与右键激活抑制的发布。
- 标题栏与协调器回归测试迁移到 v0.7.0 契约：验证完成阶梯固定点、阻塞原因、工作区边界保留部分结果，并移除约 1400 行被取代的随机/预算搜索覆盖。
- 文档清单校验将版本发布说明视为补充文档，避免把 `RELEASE_NOTES_0.x.y.md` 误判为维护文档集合成员。

## 验证状态

本地 Debug、Release 配置与构建成功，两种配置的完整 33 项测试均通过，文档与发布包测试通过。标签推送触发完整 CI；只有 CI 通过后工作流才自动创建 GitHub Release 并上传 ZIP。
